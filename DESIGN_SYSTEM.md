# Design System

## Core
- **Framework**: React + Tailwind CSS
- **Component Library**: Shadcn UI
- **Font**: Inter / Sans-serif

## Colors
- **Primary**: Blue-600 (Light), Blue-500 (Dark)
- **Background**: White (Light), Zinc-950 (Dark)
- **Surface**: Zinc-100 (Light), Zinc-900 (Dark)
- **Text**: Zinc-950 (Light), Zinc-50 (Dark)

## Components
### Layout
- **Sidebar**: Fixed width (250px), hidden on mobile (drawer).
- **Chat Area**: Flex-grow, scrollable.

### Authentication
- **Card**: Centered, shadow-lg.
- **Form**: Vertical stack with labels.

### Chat
- **Message Bubble (Me)**: Primary Color, Right aligned.
- **Message Bubble (Others)**: Surface Color, Left aligned.

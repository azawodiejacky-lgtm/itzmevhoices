# GEMINI Project Documentation

## Project: Real Time Messaging App
A modern messaging application built with React, Vite, Tailwind CSS, and Shadcn UI.

## Tech Stack
- **Frontend**: React 19, Vite
- **Styling**: Tailwind CSS 3.4, Shadcn UI
- **State Management**: Zustand
- **Routing**: React Router DOM 7
- **Icons**: Lucide React

## Status
- [x] Project Initialization
- [x] UI Design System (Shadcn + Tailwind)
- [x] Authentication (Mock Service)
- [x] Real-time Chat (Mock Service)
- [x] Responsive Dashboard

## Features
- **Login/Signup**: Secure authentication flow.
- **Channels**: Create and join channels.
- **Chat**: Real-time message updates (simulated).
- **Profile**: User management.
